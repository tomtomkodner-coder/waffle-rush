# Handasaim

אפליקציית מערכת שעות ולוח מבחנים לתיכון הנדסאים הרצליה. הנתונים נמשכים בזמן אמת מהאתר של בית הספר.

**להורדת האפליקציה:** [update/handasaim-app.apk](update/handasaim-app.apk)

הענף הזה (`handasaim`) מחזיק רק את קבצי האפליקציה. האפליקציה בודקת את `update/version.json` בכל פתיחה ומתעדכנת לבד:
- `web.zip` הוא העיצוב והקוד (מתעדכן בלי התקנה מחדש)
- `handasaim-app.apk` הוא האפליקציה עצמה

המשחק Waffle Rush נמצא בענף `master` ולא הושפע.
