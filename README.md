# Waffle Rush

A single-file HTML5 arcade game — bounce a Belgian waffle up a candy tower. Plays on web,
and ships as a native Android/iOS app (Capacitor).

**Play:** open `index.html`, or the GitHub Pages site for this repo.

- Google Sign-In (web) + AdSense H5 web ads need a real HTTPS origin (this Pages URL).
  See `ACCOUNTS-AND-ADS-SETUP.md` for the one-client-id setup across web/Android/iOS.
